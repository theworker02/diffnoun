# diffnoun

<img src="docs/logo.svg" alt="diffnoun mark" width="72" height="72">

Read a unified diff from stdin or a file and print add, remove, and change lines from +++ / --- / @@ headers.

## Install

```bash
git clone https://github.com/theworker02/diffnoun.git
cd diffnoun
npm install -g .
```

## Usage

```bash
diffnoun patch.diff
```
