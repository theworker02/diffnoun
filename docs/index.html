diffnoun

Read a unified diff and print add FILE / remove FILE / change FILE from ---, +++, and @@ headers.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

Reviewing a patch as raw hunks is slow. diffnoun reduces a unified diff to the nouns: which paths appeared, disappeared, or changed.

Reviewers, changelog authors, and CI jobs that need a file-level summary of a patch without running git.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/diffnoun.git
diffnoun --help
node src/cli.js --help

Synopsis: diffnoun [options] [file]

See the full CLI reference for every flag, exit code, and example.

diffnoun 1.00 (1.0.0)

Usage:
  diffnoun [options] [file]
  git diff | diffnoun

Summarize a unified diff as:
  add FILE
  remove FILE
  change FILE

A file is emitted only after a --- line, a +++ line, and an @@ hunk header.

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Arguments:
  file             Patch file to read. Omit to read stdin.

Examples:
  diffnoun patch.diff
  git diff main | diffnoun

Examples

Success

A patch that adds, removes, and changes files.

diffnoun changes.diff
add new.js
remove gone.js
change keep.js

Failure

Missing file path that does not exist.

diffnoun ./no-such.diff

stderr reports the Node fs error and the process exits 1.
